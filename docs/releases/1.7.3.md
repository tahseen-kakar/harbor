Harbor 1.7.3 improves download controls and makes the interface more stable.

- Add custom HTTP request headers from Advanced Settings when adding a download.
- Set Unlimited, Balanced, Quiet, or Custom speed profiles for individual downloads. The speed column shows an icon when a download uses limits that differ from the global settings.
- Manage multiple selected downloads from a grid of actions in the inspector.
- Resize the inspector and keep its last width when reopening it.
- View total download and upload speeds in a separate toolbar pill with a stable width.
- Keep table columns stable when opening the inspector, with horizontal scrolling for overflow.
- Use cleaner download details, a full-width header, and clearer status and transfer information.
- Find download and upload limits together under Custom Limits. Folder paths and buttons now share one row, with long paths shortened to fit.
- Reduce repeated formatting and unnecessary updates while viewing download details.
- Fix request-header handling during resumed downloads, redirects, and torrent handoffs.
