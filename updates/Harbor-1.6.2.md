## What’s new

- Add multiple links in one Add Download window. Special thanks to [@acryllect](https://github.com/acryllect) for the contribution that helped make this possible.
- Preview completed downloads with Quick Look.
- Start Harbor at login and prevent sleep while downloads are active.
- Select Unlimited, Balanced, Quiet, or Custom traffic modes and set torrent share limits.
- Hand supported download links from browsers and other apps to Harbor.
- Improved torrent reliability, duplicate detection, media progress, and safe resume-file cleanup without deleting downloaded files.
- Cleaner Add Download layout, simpler toolbar menus, and sorting from table headings.
