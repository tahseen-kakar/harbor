# Harbor 1.6.0

This release improves media downloads that use yt-dlp.

- Choose separate video and audio formats.
- See clearer format details, such as resolution, codec, frame rate, HDR, container, and estimated size.
- Use **Try as Media** for supported links that Harbor does not detect automatically.
- Recover when a selected media format is no longer available.
- Prevent media links from downloading an HTML page as a normal file.
- Improve media checks, format matching, retry behavior, and size estimates.

Special thanks to [@QZGao](https://github.com/QZGao), whose work in [PR #51](https://github.com/thsnkhn/harbor/pull/51) made this release possible.
