Harbor 1.7.1 improves download stability and bundled media support.

- Adds bundled Deno support for yt-dlp JavaScript challenges.
- Adds audio-only media downloads.
- Limits torrent metadata, helper output, and browser-session memory use.
- Stops the aria2 engine when Harbor exits, including after forced termination.
- Improves direct-download filenames, HTML detection, and relaunch behavior.
